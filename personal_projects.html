Game Archive

Web Development · Interactive Games

In Progress

I designed it to recreate the nostalgic feeling of classic game collections while keeping the interface approachable and easy to navigate. Right now it has rock-paper-scissors, hangman, coin flipping, and dice rolling.

I'm actively adding new games, refining existing features, and improving the overall user experience.

Beehavior-inator

Cybersecurity · Artificial Intelligence

Functional Prototype

Beehavior-inator is a honeypot system I built to capture and analyze potentially malicious user activity.

It records attacker interactions and sends structured logs to a large language model, which organizes the data, explains notable behavior, and suggests improvements to how the honeypot is configured and monitored.

This project let me explore how cybersecurity monitoring, automated log interpretation, and AI-assisted analysis work together.

Ghost House

Unity · Game Development

Completed Project

Ghost House is a complete Unity game I made with three connected gameplay sections that flow together as one experience.

  • An anomaly-detection section that challenges players to identify unusual environmental changes
  • A seven-room puzzle-solving sequence
  • A parkour-focused platforming section

It required a lot of level planning, game logic, interaction design, testing, and coordination between multiple gameplay systems.
